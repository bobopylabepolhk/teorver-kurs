# Анализ связи между средней зарплатой и стоимостью квадратного метра жилья в Санкт-Петербурге


В работе исследуется статистическая взаимосвязь между двумя признаками за период с февраля 2019 года по февраль 2026 года:

- средняя зарплата по СПБ и ЛО ([источник](https://78.rosstat.gov.ru/folder/27950));
- стоимость 1м² в новостройках Санкт-Петербурга по данным объявлений ДомКлик ([источник](https://blog.domclick.ru/analytics/detailed/offers/sankt-peterburg-grafik-bez-ucheta-komnat?periodStart=2026-05-01&topSlug=offers_med_square_price)).

Задание:

- 1) Для каждого признака построить гистограмму и эмпирическую функцию распределения.

- 2) Найти числовые характеристики этих показателей: выборочное среднее, дисперсию (смещённую и несмещённую), коэффициент вариации.

- 3) Выдвинуть и проверить гипотезу о нормальном распределении признака (критерий сhi2; уровень значимости α=0.05).

- 4) Построить диаграмму рассеяния (поле корреляции).

- 5) Вычислить выборочный коэффициент корреляции Пирсона. Проверить гипотезу о его значимости (принять нулевую гипотезу H0, что ρ=0).

- 6) Построить линейное уравнение регрессии Y на X.

- 7) Сделать выводы о силе связи X и Y, и о том, можно ли использовать регрессию для прогноза.

Графики построены с помощью **Recharts**, а вычисления выполнены на **TypeScript**.

## Методика исследования

В работе используются стандартные методы математической статистики:

- описательная статистика;
- эмпирическая функция распределения;
- проверка нормальности по критерию χ²;
- корреляционный анализ;
- линейная регрессия.

Цель исследования — оценить характер и силу связи между средней заработной платой и ценой квадратного метра жилья, а также проверить, можно ли использовать регрессию для прогноза.
